## Konsep
Satu meja zamrud. Di tengah, batu hitam berbingkai perak (Hajar Aswad sebagai benda, tanpa orang, tanpa tangan) bersinar pelan. Alur sederhana: pilih paket, DP, kode kupon unik, pemenang diumumkan. Empat kartu tingkat (Silver, Gold, Platinum, Diamond) berdiri berurutan di meja; tiap kartu menyala saat disebut dan memperlihatkan dua angka: DP dan harga paket pemenang. Gerak dari kartu, cahaya, kamera; tanpa makhluk bernyawa. Hook memakai kata "cium Hajar Aswad" sebagai impian; visual hanya benda. Ajakan tombol emas `umroh.h2c.or.id`.

## Fakta (dicek ke repo h2c-umroh, cabang `H2C-Umroh`, commit f9058a4, 26 Nov 2026)
- Tingkat dan harga paket pemenang: Silver DP Rp500.000 → Rp20.000.000; Gold DP Rp1.000.000 → Rp15.000.000; Platinum DP Rp2.500.000 → Rp12.500.000; Diamond DP Rp5.000.000 → Rp10.000.000.
- Pemenang MEMBAYAR harga paket (bukan tiket gratis); hadiah tidak dapat diuangkan; berlaku untuk paket promo dan reguler bintang 3 periode 2027.
- Satu pemenang per tingkat, satu akun maksimal satu tingkat; satu kupon per akun per tingkat; hanya yang belum mengambil paket umroh 2027; DP tetap menjadi cicilan; kupon gugur bila reservasi dibatalkan.
- Dari Bos (27 Nov): kode unik diberikan setelah DP dicek, data kode dipegang admin, fitur undian di situs tetap tersembunyi, undian offline. Situs sedang disiapkan di sesi terpisah (paket "Hajar Aswad" x2, tingkat, kode unik); isi layar video mengikuti hasilnya.

## Risiko / asumsi (butuh keputusan Bos)
1. **"Umroh 10 juta"**: hanya tingkat Diamond (pemenang membayar Rp10 jt). Hook jujur karena kata "bisa" + angka tiap tingkat disebut, tetapi tidak boleh diubah jadi "gratis" atau "tiket".
2. **"Menabung"**: tabungan dimatikan di situs; naskah memakai "DP" (dan DP jadi cicilan). Bila Bos ingin kata "menabung", perlu persetujuan karena bisa memicu isu izin gateway.
3. **Perumpamaan "cium Hajar Aswad"**: dipakai sebagai impian; tidak ada klaim akan dapat mencium (antrean di Masjidil Haram tidak dijanjikan). Mau diberi penafian singkat di caption?
4. **Jadwal undian dan batas kupon belum ada**: naskah tidak menyebut tanggal.
5. **Layar video**: menunggu sesi situs (paket Hajar Aswad, tingkat, kode unik). Sebelum jadi, layar dibuat replika berlabel "contoh".
6. Suara dan kunci ElevenLabs lewat Bos (MP3 diberikan Bos), seperti video sebelumnya.
